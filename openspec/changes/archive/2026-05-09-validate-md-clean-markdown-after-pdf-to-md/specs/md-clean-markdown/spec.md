## ADDED Requirements

### Requirement: Page marker preservation rule (Regra 7)

The system SHALL preserve all page markers intact. The recognized formats are:
- **Primary:** `[[Pág. N]]` — format generated by `pdf-to-md` (mandatory support)
- **Legacy:** `<!-- page N -->` and variants (`<!-- page N: empty -->`, `<!-- page N: extraction_failed -->`, `<!-- page N: scanned_no_ocr -->`) — backward compatibility

`PAGE_MARKER_RE` MUST cover both formats. The `--no-markers` flag MUST suppress preservation of both formats.

Proibição absoluta: a limpeza NEVER converts `[[Pág. N]]` to `<!-- page N -->` or vice versa.

#### Scenario: Primary marker on its own line is preserved
- **WHEN** the input line is exactly `[[Pág. 1]]\n`
- **THEN** the output contains `[[Pág. 1]]\n` unchanged

#### Scenario: Primary marker inline in text is preserved
- **WHEN** a line contains `[[Pág. N]]` as part of longer text
- **THEN** the entire line is passed through unchanged (no trailing-whitespace removal, no bullet normalization)

#### Scenario: Legacy HTML comment marker is preserved
- **WHEN** the input line is `<!-- page 3 -->`
- **THEN** the output contains `<!-- page 3 -->` unchanged

#### Scenario: --no-markers flag disables preservation for both formats
- **WHEN** `--no-markers` is passed and input contains both `[[Pág. 1]]` and `<!-- page 2 -->`
- **THEN** both lines pass through the normal cleaning pipeline (markers not specifically protected)

## ADDED Requirements

### Requirement: SKILL.md declares primary marker format

`SKILL.md` SHALL document `[[Pág. N]]` as the primary page marker format and `<!-- page N -->` as legacy. The "Preserva marcadores de página" statement in the skill description MUST list both formats explicitly.

#### Scenario: SKILL.md updated
- **WHEN** SKILL.md is read
- **THEN** it mentions `[[Pág. N]]` as primary and `<!-- page N -->` as legacy in the page marker preservation description

---

### Requirement: Reference examples use primary marker format

`references/exemplo_entrada.md` and `references/exemplo_saida.md` SHALL use `[[Pág. N]]` as the primary marker format in their examples. Legacy `<!-- page N -->` may appear as a secondary example.

#### Scenario: exemplo_entrada.md contains primary marker
- **WHEN** `references/exemplo_entrada.md` is read
- **THEN** it contains at least one `[[Pág. N]]` example (not exclusively `<!-- page N -->`)

#### Scenario: exemplo_saida.md preserves primary marker from input
- **WHEN** `references/exemplo_saida.md` is read
- **THEN** the `[[Pág. N]]` markers from the input example appear unchanged in the output example

### Requirement: End-to-end validation with real pdf-to-md output

The skill MUST be validated using the real output from `pdf-to-md` available at `var/output/pdf-to-md/arquivo_escaneado.md`.

#### Scenario: Real pdf-to-md output processed without marker loss
- **WHEN** `clean_markdown.py` processes `var/output/pdf-to-md/arquivo_escaneado.md`
- **THEN** all `[[Pág. N]]` markers from the input appear in the output

#### Scenario: validate_output.py confirms marker integrity on real file
- **WHEN** `validate_output.py` is run on the cleaned output of `arquivo_escaneado.md`
- **THEN** it reports zero marker errors
